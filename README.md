# Finance Control v3

Мобильное web/PWA-приложение для личных финансов и выхода из долгов. Интерфейс переработан под premium dark mobile wallet style.

## Что улучшено в v3
- переработана визуальная система: единые отступы, радиусы, типографика, контраст и mobile-first layout;
- плавающая нижняя навигация и мобильные bottom-sheet формы;
- крупный главный баланс с режимом скрытия;
- обычные расходы отделены от платежей по долгам, поэтому бюджет не искажается;
- безопасный дневной лимит рассчитывается по оставшемуся месячному бюджету;
- необязательный день зарплаты и неснижаемый резерв;
- предупреждения о приближающихся и просроченных платежах;
- стратегии Avalanche и Snowball;
- сравнение Avalanche vs Snowball по сроку и расчётным процентам;
- прогноз даты полного закрытия долгов;
- запись платежа автоматически уменьшает долг и создаёт расходную операцию;
- редактирование и удаление операций и долгов;
- поиск и фильтры операций;
- категории расходов за текущий месяц;
- экспорт/импорт JSON;
- PWA manifest и offline cache для GitHub Pages/HTTPS;
- автоматическая миграция локальных данных из v2/v1.

## Как считать стартовый баланс
`Стартовый баланс` — это сумма денег на момент, когда начинается учёт в приложении. Все добавленные после этого доходы увеличивают баланс, расходы уменьшают.

## GitHub Pages
1. Загрузи **все файлы этой папки** в корень репозитория.
2. GitHub → Settings → Pages.
3. Source: Deploy from a branch → `main` / `(root)`.
4. После публикации открой ссылку на iPhone → Share → Add to Home Screen.

## Приватность
Финансовые данные не отправляются на сервер и хранятся в `localStorage` текущего браузера. Для переноса или резервной копии используй экспорт JSON.

> Debt Planner — приблизительная модель. Реальное начисление процентов, комиссии и банковские правила могут отличаться.
